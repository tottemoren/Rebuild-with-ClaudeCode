# 要件定義

> **サービス名：Rebuild**

---

## 1. サービス概要

Rebuildは、ユーザーが作成したイラスト素材を利用し、ストーリーを基にコマを自由に配置しながら漫画を制作できるWebアプリケーションである。

ストーリーとイラスト素材をそれぞれ独立した資産として管理し、必要に応じて組み合わせることで、物語全体の構成を維持しながら柔軟に漫画を制作できる環境を提供する。

---

## 2. 開発背景

現在、漫画制作に利用されるイラスト制作ソフトやアプリケーションは数多く提供されており、レイヤー機能などを利用してイラストを制作・編集する環境は充実している。

一方で、これらのツールはイラスト制作そのものを主な目的としており、ストーリーの構成や素材の再利用を前提とした漫画制作を支援するものではない。

また、一般的な漫画制作では、ストーリーを考案した後にネームを作成し、それを基に完成原稿へと仕上げていく制作フローが広く採用されている。そのため、ストーリーとイラスト素材を独立して管理し、それらを組み合わせながら漫画を構成するという制作手法は一般的ではなく、そのような制作を支援する環境も十分に整備されていない。

---

## 3. サービスの目的

本サービスは、ストーリーとイラスト素材を独立した資産として管理し、それらを柔軟に組み合わせながら漫画を制作できる環境を提供することを目的とする。

これにより、

- 同一のイラスト素材を複数の作品で再利用できる
- ストーリーの変更に応じて漫画全体の構成を柔軟に見直せる
- 創作活動の効率化を支援できる

また、従来の漫画制作フローを置き換えることを目的とするのではなく、新たな漫画制作手法という選択肢を提供し、多様な創作スタイルを支援することを目指す。

---

## 4. ターゲットユーザー

本サービスの主なターゲットユーザーは以下のとおりとする。

- 趣味で漫画制作を行うユーザー
- 同人作品を制作するクリエイター
- 商業作品を制作する漫画家
- 漫画制作を学ぶ学生

## 6. 収益モデル

本サービスは、第三者広告配信サービスを利用した広告掲載を収益源とする。

| 項目 | 内容 |
|---|---|
| 広告掲載方式 | 第三者広告配信サービス（Google AdSense等を想定。具体的な提供事業者は別途選定する） |
| 掲載箇所 | ホーム画面・メモ管理画面（[02-screen-design](../02-screen-design)のワイヤーフレームに広告エリアとして明記済み）。他画面への拡大は別途検討する |
| 広告掲載基準 | 全年齢向けサービスとしての掲載基準に準拠する広告のみを許可する（7章の年齢制限方針に準ずる） |

有料プラン・広告非表示オプションなどの要否は現時点では未定とし、必要に応じて別途検討する。

## 7. 著作権・利用規約に関する方針

本サービスに投稿されるイラスト素材・ストーリー・漫画等のコンテンツに関する著作権の扱いは、以下の方針とする。

- コンテンツの著作権は投稿したユーザー本人に帰属する。運営者はコンテンツの著作権を取得しない。
- ただし投稿者は、サービスの運営・表示・宣伝等に必要な範囲において、運営者に対して非独占的かつ無償の利用許諾（ライセンス）を付与するものとする（動画投稿サービス等で一般的に採用されている枠組みに準ずる）。
- 本サービスは全年齢向けサービスとして運営し、R18等の成人向け表現を含むコンテンツの投稿は禁止する。

上記方針を踏まえた正式な利用規約・プライバシーポリシーの文書化は別途行うものとし、本項目はその基本方針のみを示す。
