# 要件定義

> **サービス名：Rebuild**

---

## 1. サービス概要

Rebuildは、用意されたイラスト素材や自分で描いたイラストを組み合わせ、ストーリーを基にコマを自由に配置しながら漫画（ネームや完成した漫画）を制作できるWebアプリケーションである。

アイデア・ストーリー・イラスト素材をそれぞれ独立した資産として管理し、必要に応じて組み合わせることで、1つのストーリーから何度でも漫画を作り直せる環境を提供する。

---

## 2. 開発背景

現在、漫画制作に利用されるイラスト制作ソフトやアプリケーションは数多く提供されており、レイヤー機能などを利用してイラストを制作・編集する環境は充実している。

一方で、これらのツールはイラスト制作そのものを主な目的としており、ストーリーの構成や素材の再利用を前提とした漫画制作を支援するものではない。また、絵を描くことを前提としているため、**絵を描けない人が、考えた物語を漫画の形で表現する手段**は限られている。

一般的な漫画制作では、ストーリーを考案した後にネーム（コマ割り・構図・セリフを示した下書き）を作成し、それを基に完成原稿へと仕上げていく。プロの漫画家は自分の絵柄を持っているため、ラフな線のネームでも作品の雰囲気が伝わる。しかし、絵を描けない原作志望者などは、ストーリーに合う絵柄を探しながら表現する必要があり、そのような制作を支援する環境は十分に整備されていない。

---

## 3. サービスの目的

本サービスは、アイデア・ストーリー・イラスト素材を独立した資産として管理し、それらを柔軟に組み合わせながら漫画を制作できる環境を提供することを目的とする。

これにより、

- 絵を描けない人でも、ストーリーに合うイラストを選んで並べることで、物語を漫画の形で表現できる
- 同一のイラスト素材を複数の作品で再利用できる
- 1つのストーリーから、絵柄や構成の異なる漫画を何度でも作り直せる
- 創作活動の効率化を支援できる

また、従来の漫画制作フローを置き換えることを目的とするのではなく、新たな漫画制作手法という選択肢を提供し、多様な創作スタイルを支援することを目指す。

---

## 4. ターゲットユーザー

本サービスの主なターゲットユーザーは、次の2種類とする。プロトタイプでは両方を想定して作り、利用者の反応を見て改善する（[ロードマップ](../00-roadmap.md) 段階3）。

| 種類 | 特徴 | 主な使い方 |
|---|---|---|
| 絵を描けない原作者 | ストーリーを考えるのが得意だが、絵は描けない。漫画原作者を目指す人、趣味で物語を作る人など | 用意されたイラスト素材から、ストーリーに合う絵柄を探して並べ、ネームや漫画を作る |
| 自分でイラストを描く人 | 自分の絵柄を持つ。趣味・同人で漫画を描く人、漫画制作を学ぶ学生など | 自分のイラストを取り込み、組み合わせ直して何度でも漫画を作る |

|---|---|---|---|

| REQ-003 | ダッシュボード表示 | 登録済みのアイデア帳・ストーリー・漫画を一覧表示し、検索する。一覧から編集画面を開く。漫画からは、つながっているアイデア帳・ストーリーを見比べられる。初めての利用者向けに「何から始めるか」の入口を表示する | [SCR-003 ホーム画面](../02-screen-design/specifications/Home.md) |

| REQ-005 | ストーリー管理 | タイトル・あらすじ・ジャンルの設定、セリフの作成を行う。作成中はアイデア帳を参照できる。新規作成と編集は同じ画面で行う。ストーリーから、そのストーリーを使った漫画の作成を始められる | [SCR-005 ストーリー管理画面](../02-screen-design/specifications/StoryCreate.md) |
| REQ-006 | （廃止）漫画作成のストーリー・素材選択 | ストーリーと素材フォルダの選択は、漫画作成画面の中で行う形に変更したため、専用画面は廃止する（REQ-007 に統合） | [SCR-006 漫画作成-ストーリー選択画面](../02-screen-design/specifications/TopicChoice.md)（廃止予定） |

| REQ-009 | 素材管理 | イラスト素材を一覧で探す・見比べる・整理する・追加する。フォルダは入れ子にでき、後から自由にまとめ直せる。自分のイラストは「この端末だけに保存（サーバーに送らない）」か「アカウントに保存」を選べる。素材ごとに出典・利用条件を記録する | 素材画面（新設予定） |
| REQ-010 | 見本データ | 見本のアイデア帳・ストーリー・漫画・イラスト素材を初期データとして用意する。一覧では「見本」と表示し、利用者は削除でき、設定画面から復元できる | ホーム画面、設定画面（新設予定） |
| REQ-011 | ログイン前の体験 | ログインしなくても全画面を見られる。漫画作成画面は操作でき、作ったものはブラウザに保存し、登録時に引き継ぐ（書き出しはロゴ入り）。アイデア帳・ストーリー・素材の画面は見本を見られ、作成・編集などには「アカウントが必要です」と表示する | 各画面 |
| REQ-012 | 公開ページ | ログインせずに見られるトップ（サービス紹介）・使い方・見本の漫画・読み物（ネームの作り方など）を用意する | トップ画面・使い方画面・読み物画面（新設予定） |
| REQ-013 | パスワードの再設定 | パスワードを忘れた場合に、登録したメールアドレスへ再設定用のリンクを送り、新しいパスワードを設定できる | ログイン画面（画面の設計は限定公開の前に行う） |

## 6. 収益モデル

本サービスは、第三者広告配信サービスを利用した広告掲載を収益源とする。

| 項目 | 内容 |
|---|---|
| 広告掲載方式 | 第三者広告配信サービス（Google AdSense等を想定。具体的な提供事業者は別途選定する） |
| 掲載箇所 | ホーム画面・アイデア帳の画面・ストーリー管理画面・素材画面、および公開ページ。漫画作成画面とログイン・登録画面には掲載しない |
| 広告掲載基準 | 全年齢向けサービスとしての掲載基準に準拠する広告のみを許可する（7章の年齢制限方針に準ずる） |
| 審査への対応 | 広告配信サービスの審査では、ログインせずに見られる内容が評価されるため、公開ページ（REQ-012）と読み物を整えてから申請する |

有料プラン・広告非表示オプションなどの要否は現時点では未定とし、必要に応じて別途検討する。

## 7. 著作権・利用規約に関する方針

本サービスに投稿されるイラスト素材・ストーリー・漫画等のコンテンツに関する著作権の扱いは、以下の方針とする。

- コンテンツの著作権は投稿したユーザー本人に帰属する。運営者はコンテンツの著作権を取得しない。
- ただし投稿者は、サービスの運営・表示・宣伝等に必要な範囲において、運営者に対して非独占的かつ無償の利用許諾（ライセンス）を付与するものとする（動画投稿サービス等で一般的に採用されている枠組みに準ずる）。
- 本サービスは全年齢向けサービスとして運営し、R18等の成人向け表現を含むコンテンツの投稿は禁止する。

上記方針を踏まえた正式な利用規約・プライバシーポリシーの文書化は別途行うものとし、本項目はその基本方針のみを示す。正式な規約を作成する際は、利用許諾の範囲（宣伝への利用など）、イラスト素材の扱い（AIの学習に利用しないこと、削除時の扱いなど）を、イラストを描く利用者が安心して使える内容になるよう見直す。
