# 要件定義

## 1. サービス概要
　Rebuildは、ユーザーが作成したイラスト素材を利用し、ストーリーを基にコマを自由に配置しながら漫画を制作できるWebアプリケーションである。
　ストーリーとイラスト素材を個別に管理し、それらを必要に応じて組み合わせることで、物語の構成を維持しつつ効率的に漫画制作を行える環境を提供する。
　Rebuildは、従来の漫画制作フローを置き換えることを目的とするものではなく、新たな制作手法の選択肢を提供することを目指す。

---

## 2. 開発背景
現在、漫画制作に利用されるイラスト制作ソフトやアプリケーションは数多く提供されており、レイヤー機能などを利用して漫画を作成・編集する環境は充実している。一方で、これらのツールはイラスト制作そのものを主な目的としており、ストーリーの構成や素材の再利用を前提とした漫画制作を支援するものではない。

一般的な漫画制作では、ストーリーを考案した後にネームを作成し、それを基に完成原稿へと仕上げていく手法が広く採用されている。本サービスでは、この従来の制作フローとは異なるアプローチとして、ストーリーとイラスト素材をそれぞれ独立した資産として管理し、それらを自由に組み合わせながら漫画を構成する制作手法を提案する。

---

## 3. サービスの目的
本サービスは、ストーリーとイラスト素材を独立した資産として管理し、それらを柔軟に組み合わせながら漫画を制作できる環境を提供することを目的とする。

これにより、同一のイラスト素材を複数の作品で再利用したり、ストーリーの変更に応じて漫画全体の構成を見直したりすることを容易にし、創作活動の効率化を支援する。

また、従来の漫画制作フローを置き換えることを目的とするのではなく、新たな漫画制作手法の選択肢を提供し、多様な創作スタイルを支援することを目指す。

---

## 4. ターゲットユーザー
- 趣味で漫画制作を行うユーザー
- 同人作品を制作するクリエイター
- 商業作品を制作する漫画家
- 漫画制作を学ぶ学生
