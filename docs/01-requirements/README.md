# 要件定義

## 1. サービス概要
　Rebuildは、ユーザーが作成したイラスト素材を利用し、ストーリーを基にコマを自由に配置しながら漫画を制作できるWebアプリケーションである。
　ストーリーとイラスト素材を個別に管理し、それらを必要に応じて組み合わせることで、物語の構成を維持しつつ効率的に漫画制作を行える環境を提供する。

---

## 2. 開発背景
　漫画制作ツールは数多く存在するが、多くは完成したページの編集を主な目的としている。
　一方で、ストーリー構成と漫画制作を関連付けながら管理できるサービスは少なく、物語全体を確認しつつ制作を進めることが難しいという課題がある。

---

## 3. サービスの目的
　本サービスは、ストーリーと漫画制作を一元管理できる環境を提供することを目的とする。
　ユーザーが物語全体の構成を確認しながら漫画制作を進められることで、制作効率の向上や作品品質の改善を支援する。

---

## 4. ターゲットユーザー
- 趣味で漫画制作を行うユーザー
- 同人作品を制作するクリエイター
- 商業作品を制作する漫画家
- 漫画制作を学ぶ学生
