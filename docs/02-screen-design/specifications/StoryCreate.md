# ストーリー管理画面

![ストーリー管理画面](../wireframes/StoryCreate.drawio.png)

---

## 1. 画面概要

ユーザーがストーリー（あらすじ・ジャンル・セリフ台本）を作成・編集する画面。
画面右側に参照エリアがあり、自分のメモ一覧と自分が過去に作成したストーリー一覧を切り替えて表示しながら作業できる。過去の自作ストーリーやメモの内容を参考にしつつ、新しいストーリーを組み立てられる。

---

## 2. 画面情報

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-005 |
| 画面名 | ストーリー管理画面 |
| URL | /story |
| 権限 | ログインユーザー |
| 遷移元 | ホーム画面、メモ管理画面、漫画作成 - ストーリー選択画面 |
| 遷移先 | ホーム画面、メモ管理画面、漫画作成 - ストーリー選択画面、設定画面、アカウント情報編集画面、ログイン画面（ログアウト時） |

---

## 3. 画面レイアウト

| No | 項目 | 説明 |
|----|------|------|
| 1 | ヘッダー | サービス名ロゴ、サイドバー切り替えボタン、検索バー、参照エリア表示切り替えボタン（メモ／過去のストーリー）、設定ボタン、アカウントボタン、ログアウトボタンを表示 |
| 2 | サイドメニュー | 各画面へ遷移するためのボタンを表示（切り替えボタンで表示・非表示を切り替え可能） |
| 3 | ストーリー情報エリア | タイトル、あらすじ、ジャンル（最大3つ）を入力する |
| 4 | セリフ入力エリア | 人物名とセリフを組み合わせてストーリーの台本を作成し、保存する |
| 5 | 参照エリア | 自分のメモ一覧、または自分が過去に作成したストーリー一覧を表示し、新しいストーリー作成の参考として閲覧できる。表示内容は切り替えボタンで変更する |

---

## 4. 操作

| 操作 | 動作 |
|------|------|
| ロゴをクリック | ストーリー管理画面を再読み込みする |
| サイドバー切り替えボタンをクリック | サイドメニューの表示・非表示を切り替える |
| 参照エリア表示切り替えボタンをクリック | 参照エリアの表示内容を「自分のメモ一覧」と「自分の過去のストーリー一覧」で切り替える |
| 設定をクリック | 設定編集画面を開く |
| アカウントアイコンをクリック | アカウント情報編集画面を開く |
| ログアウトをクリック | ログイン画面へ遷移する |
| 検索バーに入力・検索ボタンをクリック | 検索条件に一致するストーリーを表示する |
| タイトル・あらすじ・ジャンルを入力 | 各入力欄にカーソルを合わせ、任意の文字列を入力・選択する |
| 人物名・セリフを入力 | セリフ入力エリアにカーソルを合わせ、任意の文字列を入力する |
| 保存ボタンをクリック | 入力中のストーリー・セリフを保存する |
| 参照エリアのメモ／ストーリーをクリック | 該当メモ、または該当ストーリーの内容（あらすじ・セリフ）をプレビュー表示する |
| ホームをクリック | ホーム画面へ遷移する |
| メモをクリック | メモ管理画面へ遷移する |
| 漫画創作をクリック | 漫画作成 - ストーリー選択画面へ遷移する |

---

## 5. 表示内容

- 参照エリアのメモ・ストーリーは、いずれも更新日時の降順で表示する。
- 参照エリアには自分が作成したメモ・ストーリーのみを表示する（他ユーザーのものは表示しない）。
- ジャンルは最大3つまで設定できる。

---

## 6. エラー

- タイトルが未入力の場合は保存できない旨のメッセージを表示する。
- 保存に失敗した場合はエラーメッセージを表示する。

---

## 7. 備考

- あらすじ・セリフの最大文字数は別途仕様として確定する。
- ジャンルの選択方式（自由入力かプリセット選択か）は別途確定する。
- セリフの並び替え・削除操作の有無はワイヤーフレーム上に明示されていないため、詳細設計時に確認する。
