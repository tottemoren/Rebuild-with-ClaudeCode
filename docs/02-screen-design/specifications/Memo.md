# メモ管理画面

![メモ管理画面](../wireframes/Memo.drawio.pngpng)

---

## 1. 画面概要

ユーザーがメモの作成を行う画面。

---

## 2. 画面情報

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-004 |
| 画面名 | メモ管理画面 |
| URL | /memo |
| 権限 | ログインユーザー |
| 遷移元 | ホーム画面、ストーリー創作画面、漫画創作画面 |
| 遷移先 | ホーム画面、ストーリー創作画面、漫画創作画面、設定画面、アカウント情報編集画面、ログイン画面（ログアウト時） |

---

## 3. 画面レイアウト

| No | 項目 | 説明 |
|----|------|------|
| 1 | ヘッダー | サービス名ロゴ、検索バー、設定ボタン、アカウントボタン、ログアウトボタンを表示 |
| 2 | サイドメニュー | 各画面へ遷移するためのボタンを表示 |
| 3 | 横書きメモ記入エリア | 横書きのメモを記入して保存できる |
| 4 | 縦書きメモ記入エリア | 縦書きのメモを記入して保存できる |
| 5 | 広告エリア | 自動でスクロールされる広告を表示 |

---

## 4. 操作

| 操作 | 動作 |
|------|------|
| ロゴをクリック | メモ画面を再読み込みする |
| 設定をクリック | 設定編集画面を開く |
| アカウントアイコンをクリック | アカウント情報編集画面を開く |
| ログアウトをクリック | ログイン画面へ遷移する |
| 検索バーに入力・検索ボタンをクリック | 検索条件に一致する文字列をハイライト表示する |
| メモに文字を記入する | メモにカーソルを合わせクリック。任意の文字を記入する |
| 保存ボタンをクリック | 記入している新しいメモを保存する |
| 削除ボタンをクリック | 記入途中のメモを削除する |
| ホームをクリック | ホーム画面へ遷移する |
| ストーリー創作をクリック | ストーリー管理画面へ遷移する |
| 漫画創作をクリック | 漫画作成画面へ遷移する |

---

## 5. 表示内容

- 新規で作成する用のメモのタイトルおよび本文を表示する。
- 広告を一定時間ごとに自動スクロール表示する。

---

## 6. エラー

- 保存に失敗した場合はエラーメッセージを表示する。
- 削除に失敗した場合はエラーメッセージを表示する。

---

## 7. 備考

- タイトルおよび本文が未入力の場合の保存可否は別途バリデーション仕様に従う。
- 削除前に確認ダイアログを表示する。
