# ホーム画面

![ホーム画面](../wireframes/home.png)

---

## 1. 画面概要

ログイン後に最初に表示される画面。
メモ・ストーリーの一覧を表示し、再度メニューにあるボタンからはそれぞれの制作画面に遷移できる。

---

## 2. 画面情報

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-003 |
| 画面名 | ホーム画面 |
| URL | /home |
| 権限 | ログインユーザー |
| 遷移元 | ログイン画面 |
| 遷移先 | メモ管理画面、ストーリー管理画面、漫画編集画面 |

---

## 3. 画面レイアウト

| No | 項目 | 説明 |
|----|------|------|
| 1 | ヘッダー | サービス名、ログアウトボタンを表示 |
| 2 | メモ一覧 | 登録済みメモを表示 |
| 3 | ストーリー一覧 | 登録済みストーリーを表示 |
| 4 | 漫画一覧 | 作成済み漫画を表示 |
| 5 | 新規作成ボタン | 各管理画面へ遷移 |

---

## 4. 操作

| 操作 | 動作 |
|------|------|
| メモをクリック | メモ編集画面を開く |
| ストーリーをクリック | ストーリー編集画面を開く |
| 漫画をクリック | 漫画編集画面を開く |
| ログアウト | ログイン画面へ遷移 |

---

## 5. 表示内容

- メモを更新日時順で表示する
- ストーリーを更新日時順で表示する
- 漫画を更新日時順で表示する

---

## 6. エラー

- 一覧取得に失敗した場合はエラーメッセージを表示する。

---

## 7. 備考

- ログインユーザーのデータのみ表示する。
