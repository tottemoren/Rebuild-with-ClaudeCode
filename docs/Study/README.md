# Study（学習ノート）

このフォルダは、Rebuild の開発を通して「**どう考え、何を学び、どこでつまずいたか**」をまとめた学習ノートです。

設計書（`docs/01〜05`）が「何を作るか」の記録なのに対し、ここは「どう進め、何を理解したか」の記録です。

> **このノートについて**
> 企画・設計・開発をAI（Claude Code）と一緒に進める中で出てきた学びを、Claude Code が整理して書いています。
> 記述は、実際のコード・ワークフロー・CHANGELOGと照らして確認しています。確認できていないことは「未確認」と書いています。

## CHANGELOG との書き分け

| | CHANGELOG | このノート（Study） |
|---|---|---|
| 目的 | 何をしたかの記録 | 何を学んだかの整理（復習用） |
| 並び方 | 日付順 | テーマ別 |
| 書く内容 | 変更したファイル、手順、確認結果 | なぜそうしたか、他の選択肢、次に同じ場面でどう考えるか、用語の意味 |
| 書くとき | 変更のたびに必ず | 学びがあったときだけ |

各項目の最後に、元になった作業の記録を `作業記録：2026-10-13（5回目）` のように小さく書いています。リンクを開き、その日のファイルの中で「Claude によるアップデート（2026-10-13・5回目）」の見出しを探すと、詳しい作業内容が分かります。

## このノートの書き方の方針

- **初学者にも分かる言葉で**書く（専門用語は用語集で説明する）
- **結論だけでなく、理由と選択肢**を書く
- **うまくいかなかったこと**も書く
- 現在のスコープ（v1）の範囲にとどめ、実装していないことを実装済みのように書かない
- 鍵・アカウントID・個人情報は書かない
