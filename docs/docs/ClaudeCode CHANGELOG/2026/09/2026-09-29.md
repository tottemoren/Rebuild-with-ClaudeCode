## Claude によるアップデート（2026-09-29）

サービス名を「Manga Rebuild（マンガリビルド）」とし、独自ドメインでの公開に対応した。

### 実施した内容

1. **独自ドメイン `mangarebuild.com` を取得**（Route 53）
   ACM（us-east-1）でSSL証明書を発行し、フロントエンド用CloudFrontに `mangarebuild.com` / `www.mangarebuild.com` を代替ドメイン名として設定。Route 53にAレコード（エイリアス、CloudFront向け）を2つ作成。

2. **CORSの許可リストに新ドメインを追加**（ユーザーが実施）
   `RebuildJavaController.java` / `UserController.java` の `@CrossOrigin` に `https://mangarebuild.com` と `https://www.mangarebuild.com` を追加。EC2上でバックエンドを再ビルドして反映。

3. **EC2への接続不可を解決**
   セキュリティグループのSSHルール（マイIP）が、作業場所（Wi-Fi）を変えたことで古いIPアドレスのまま残っており、接続がタイムアウトしていた。ルールを再設定して復旧。
