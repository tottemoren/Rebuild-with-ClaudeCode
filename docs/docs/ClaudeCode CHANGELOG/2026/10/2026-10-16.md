## Claude によるアップデート（2026-10-16・3回目）

PR #28 を本番に反映したあと、サイトが開けなくなった件を調べ、原因と対処を記録した（`feature/docs-domain-hold`）。ドキュメントだけの変更で、本番への影響はない。

### 起きたこと

1. **PR #28 の本番への反映（利用者が実施）**
   EC2 の `.env` に `INVITE_CODE` を追加してからマージし、EC2 でバックエンドを反映した。起動のログで、ユーザーの表へのメールアドレスの列と重複禁止の決まりの追加を確認し、DB でも決まりが付いたことを確認した（`Non_unique` が 0、空のままでもよい）
2. **サイトが開けない**
   利用者から「ログインできない」と連絡があり、ブラウザの Network とバックエンドのログを確認したが、何も記録されていなかった。画面の表示は `DNS_PROBE_FINISHED_NXDOMAIN` だった
3. **原因の特定**
   `dig` で名前が引けず（`NXDOMAIN`）、`whois` でドメインの状態が `clientHold`（登録会社による保留）だった。有効期限は切れていない。ドメインの登録から15日以内に、登録者のメールアドレスの確認が必要だったが、行っていなかったため、自動で停止された（登録からちょうど約15日後）。今回のアプリの変更とは関係がなかった
4. **対処（利用者が実施）**
   Route 53 から確認メールを再送信し、届いたリンクを押した。解除されたかは、時間をおいて確認する
