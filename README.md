# Rebuild

## 概要

Rebuild は、ユーザーが作画した同じイラストを使って、何度でも漫画を作成できるWebアプリケーションです。

ストーリーを確認しながら、コマ素材を自由に配置し、漫画形式で物語を視覚的に構築できるサービスを目指しています。

現在は個人開発中です。

---

## 主な機能

### 実装済み

* ログイン機能
* ログアウト機能
* ユーザー登録
* データベース連携
* React Routerによる画面遷移
* 共通レイアウト機能
* 認証機能(localstorageにユーザー情報の一時保存)
* ProtectedRoute
* パスワード暗号化（BCrypt）・Spring Security導入
* Docker対応(WindowsOS端末で同一環境構築・ブラウザ起動確認済み)
* GitHub連携

### 開発予定

** 全ページ共通 **
* 設定ボタン
* アカウントボタン(ユーザーごとのプロフィール画像)
* ロゴマークを押すと画面そのままで更新機能

** ホーム画面 **
* ホーム画面のメモ・ストーリー表示切り替えボタンとその表示機能

** メモ画面 **
* 縦型と横型のメモ書き込み・保存・削除機能

** ストーリー創作画面 **
* ストーリー画面のメモ・ストーリー表示切り替えボタンとその表示機能
* ストーリー創作・保存機能

** マンガ創作画面(TopicChoice) **
* 画像・イラストのフォルダ毎の保存機能
* カーソルを合わせた時にストーリ要素の下に、セリフ要素が表示される機能
* 最後にクリックした1個のストーリーに選択済み表示
* 「次へ」ボタンを押した際に、選択済み要素を保持したままMangaCreat画面に遷移機能

** マンガ創作画面 **
* 漫画作成機能（コマ画像のドラッグ配置・移動・削除・サーバー保存）
* 固定枠内のスクリーンショット機能（Canvas APIによるPNG書き出し）
